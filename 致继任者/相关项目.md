## 集成接口详情

### AutoOffice（6 个工具）

| 工具 | 调用方式 | 对端 API |
|------|---------|---------|
| `autooffice_health` | GET /health | 健康检查 |
| `autooffice_generate_report` | POST /api/generate | 生成 PPT/PDF/Word/LaTeX/HTML |
| `autooffice_summarize` | POST /api/summarize | 内容分析 + Mermaid 图 |
| `autooffice_enrich` | POST /api/enrich | KnowLever RAG 增强（AutoOffice 内部代理） |
| `autooffice_check_quality` | POST /api/quality | 文本去 AI 味 + 质量评分 |
| `autooffice_list_templates` | GET /api/templates | 报告模板列表 |

### KnowLever（3 个工具）

| 工具 | 调用方式 | 说明 |
|------|---------|------|
| `knowlever_query` | Python subprocess → rag.pipeline | RAG 混合检索（BM25 + 向量） |
| `knowlever_list_topics` | 直接读文件系统 | 列出 data/users/*/topics/ |
| `knowlever_ingest` | Python subprocess → rag.pipeline | 摄入文档到知识库 |

### digist（4+ 个工具，Slave 创建中）

| `digist_crawl` | POST :3800/api/crawl/trigger | 触发平台爬取 |
| `digist_search` | GET :3800/api/items/recent | 搜索已爬取数据 |
| `digist_recommend` | GET :3800/api/recommend | 个性化推荐 |

### Ecosystem Orchestration（4 个编排工具）

| 工具 | 说明 |
|------|------|
| `ecosystem_status` | 一次性检查 digist + KnowLever + 端口注册状态 |
| `ecosystem_sync_digest` | digist → KnowLever 内容同步管道 |
| `ecosystem_discover_and_learn` | 完整流水线：爬取 → 同步 → 编译知识 |
| `ecosystem_unified_search` | 统一搜索（digist 原始数据 + KnowLever RAG） |

### 对端阻塞项

| 项目 | 问题 | 影响 | 优先级 |
|------|------|------|--------|
| AutoOffice | `node_modules/` 缺失（所有依赖 UNMET） | API server 无法启动，6 个工具全部不可用 | 高 — `npm install` 即可 |
| AutoOffice | 未在 SOTAgent 项目字典注册 | 其他项目的 Agent 不知道 AutoOffice 的存在 | 中 |
| KnowLever | 知识库数据极少（data/users/ 只有 1 个目录） | RAG 检索返回空或低质量结果 | 中 — 需要批量灌数据 |
