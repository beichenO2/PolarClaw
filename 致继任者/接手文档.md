## 项目概述

MyClaw 是 AI Agent 融合平台，采用端口-适配器（六边形）架构。从旧版 OpenClaw+DeerFlow+Hermes 融合项目完全重写为 TypeScript。

### 架构决策

- **端口-适配器**：所有外部依赖通过接口隔离，任何模块可独立替换
- **TypeScript**：从旧版 JavaScript 迁移，获得类型安全
- **多轮对话**：修复旧版最大缺陷（单轮无状态），SQLite 持久化对话历史
- **隐私优先**：Channel Privacy Gateway 在所有消息路径上强制脱敏
- **自学习**：Agent 运行时可学习用户偏好、生成新技能、组合工作流

## 快速启动

```bash
cd ~/Polarisor/MyClaw
# 确保 PolarPrivate 在 8790 运行且 Vault 已解锁
npm run dev    # 开发模式（tsx watch）
# 或
npm run build && npm start  # 生产模式
```

默认开启 CLI 通道（`MYCLAW_CLI=1`），终端直接输入即可对话。
LLM 请求通过 PolarPrivate Proxy 转发（`http://127.0.0.1:8790/proxy/llm.aliyun.codingplan`），无需直接持有 API Key。

## 自学习系统架构

```
用户对话
  ↓
TrackedToolExecutor（自动记录每次工具调用）
  ↓
LearningStore（SQLite: tool_usage + feedback + tool_patterns）
  ↓
PatternDetector（检测重复调用序列）
  ↓
SkillGenerator（生成 SKILL.md + tools.ts → skills/ 目录）
  ↓
SkillRegistry（文件监听 → 热加载新技能）
  ↓
Agent 获得新工具 ← SkillComposer（工作流组合）
```

Agent 暴露的学习工具：
- `learning_record_feedback` — 记录用户纠正
- `learning_get_preferences` — 查询已学习偏好
- `learning_detect_patterns` — 分析工具使用模式
- `learning_generate_skill` — 从描述生成新技能
- `learning_list_skills` — 列出所有技能
- `learning_compose_workflow` — 创建工作流

## 注意事项

- **PolarPrivate 必须在线**：LLM 调用和隐私网关都依赖 PolarPrivate（端口 8790），Vault 需解锁
- Clock 集成需要 PolarClock 后端运行在端口 15550
- 飞书通道需要配置 App 凭证（`FEISHU_ADMIN_APP_ID` 等）
- `apiKey=proxy-managed` 是特殊标记，告知 LLM 适配器不发送 Authorization header（交由 Proxy 注入）
- 自学习生成的技能写入 `skills/auto-*` 或 `skills/custom-*`，由 SkillRegistry 文件监听自动加载
