## 项目概述

MyClaw 是 AI Agent 融合平台，采用端口-适配器（六边形）架构。从旧版 OpenClaw+DeerFlow+Hermes 融合项目完全重写为 TypeScript。

### 架构决策

- **端口-适配器**：所有外部依赖通过接口隔离，任何模块可独立替换
- **TypeScript**：从旧版 JavaScript 迁移，获得类型安全
- **多轮对话**：修复旧版最大缺陷（单轮无状态），内存管理对话历史
- **隐私优先**：Channel Privacy Gateway 在所有消息路径上强制脱敏

## 技术栈

| 组件 | 技术 |
|------|------|
| 语言 | TypeScript (ES2022) |
| 运行时 | Node.js 20+ |
| 数据库 | SQLite + FTS5 (better-sqlite3) |
| LLM | 阿里云百炼 Coding Plan (OpenAI-compatible) |
| 隐私 | PolarPrivate API (端口 8790) |

| 文件 | 说明 |
